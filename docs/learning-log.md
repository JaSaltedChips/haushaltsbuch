# Learning log

A short journal, one entry per work session or phase. The point is to put what was
learned into your own words. Write it yourself; a good entry is five or ten lines.

Keep it public-safe: no addresses, secrets, or sensitive configuration.

## Entry template

```markdown
## YYYY-MM-DD: <phase or topic>

**What I did:**
**What I expected vs what happened:**
**What I learned (in my own words):**
**What I'm still unsure about:**
**Links:** issue #, PR #, ADR-NNNN
```
